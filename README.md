# ☕ Djeroe. — Kopi, Teman & Senja

> *Ruang di dalam, tempat obrolan jadi lebih hangat.*

Sebuah website interaktif bertema kafe kopi modern bernuansa *dark coffee brown*, dirancang dengan pengalaman visual imersif, tipografi elegan (*Fraunces Serif* & *DM Sans*), dan transisi layar mulus.

---

## 🌟 Fitur Utama

- **🎬 Dynamic Splash Preloader**: Loading awal interaktif dengan persentase *real-time* (0%–100%) dan animasi tirai singkap (*wipe transition*) elegan.
- **〰️ Rhythmic Brand Typography**: Huruf judul *Djeroe.* bergerak bergelombang (*staggered wave*) secara ritmis dan interaktif saat disentuh kursor.
- **✨ 5 Interactive Scenes Navigation**:
  1. **Beranda**: *Hero section* hangat dengan cangkir kopi mengepul beranimasi uap dan tombol aksi dinamis berbalon fluida.
  2. **Tentang**: Cerita filosofi nama *Djeroe* ("di dalam") serta metrik kualitas kopi Nusantara.
  3. **Menu Lengkap & Pilihan**: Katalog 24 varian menu (Kopi, Non-Kopi, Camilan, Makanan) dilengkapi filter kategori instan, pencarian *live search*, dan kartu 3D *tilt-perspective*.
  4. **Suasana (*Ambiance*)**: Galeri akordeon 4 sudut favorit kafe (*Teras Pagi*, *Ruang Dalam*, *Meja Panjang*, *Sudut Senja*) dengan foto kafe estetik dan efek *zoom*.
  5. **Kontak**: Jam operasional dan tautan cepat ke Instagram, WhatsApp Reservasi, serta Email dengan ikon *badge* modern yang responsif.
- **🖱️ Magnetic Custom Cursor**: Kursor cincin aksen karamel yang membesar dinamis di atas elemen klik.
- **📱 Fully Responsive**: Tampilan adaptif dan nyaman dinavigasi baik di perangkat *desktop*, tablet, maupun *mobile smartphone*.

---

## 🚀 Menjalankan Secara Lokal

Cukup buka berkas `index.html` langsung di browser favorit Anda (Google Chrome, Firefox, Safari, Edge):

```bash
# Menggunakan live-server / static server (opsional)
npx serve .
# atau buka langsung berkas index.html
start index.html
```
